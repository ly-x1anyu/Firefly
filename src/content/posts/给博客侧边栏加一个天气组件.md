侧边栏一直空着一块位置，想着放个天气小组件挺实用——一眼能看到温度、空气质量，点开还能看湿度风力这些细节。本以为是个简单的活，结果踩的坑比想象中多：Astro 的 scoped 样式对动态 DOM 不生效、localStorage 缓存解包把数据搞丢、Swup 页面切换脚本不重入……

## 一、先说数据源怎么选的

博客是纯静态站，所以天气数据只能放浏览器里 `fetch`，没法在构建时拿。这意味着两件事：接口得允许跨域（CORS），而且国内那些要登录、要 Key、还常限频的接口基本可以 pass。

我最后定了三个源，按"能免 Key 就免 Key、国内优先"的原则：

| 数据源 | 适用 | Key | 说明 |
| :---: | :---: | :---: | :---: |
|  uapis.cn  |  国内（主力）  |  不需要  |  单接口返回全部数据，还反射 Origin 头放行跨域，白嫖首选  |
| 和风天气 | 国内（兜底） | 需要 | uapis 挂了或者返回空就切它，实时数据更准 |
| Open-Meteo | 国外 | 不需要 | 坐标出了中国包围盒就用它，免费且不限额 |

一句话：**三个源统一归一化成同一套数据结构**，渲染层完全不关心数据从哪来，后面换源、加源都不用动 UI。

## 一之续：开关与扩展

每个源在 `weatherConfig.ts` 里都有独立的 `true/false` 开关（`enableUapis` / `enableQWeather` / `enableOpenMeteo`），想关哪个改成 `false` 就行——关掉后组件完全不请求它、也不拿它兜底。比如把 `enableQWeather` 关了，国内就只用 uapis，挂了也不会去碰和风。

底层不是写死的 if/else，而是一个**数据源注册表**：

```javascript

const SOURCES = [

{ name: "uapis", region: "cn", enabled: C.enableUapis, fetch: (lat, lon) => fetchUapis(lat, lon) },

{ name: "qweather", region: "cn", enabled: C.enableQWeather && !!C.qweatherKey, fetch: (lat, lon) => fetchQWeather(lat, lon, C.qweatherKey) },

{ name: "openmeteo", region: "global", enabled: C.enableOpenMeteo, fetch: (lat, lon) => fetchOpenMeteoSource(lat, lon) },

];


// 先试本区 enabled 的源，全挂再跨区兜底

async function pickSource(lat, lon, region) {

const order = SOURCES.filter(s => s.region === region && s.enabled)

.concat(SOURCES.filter(s => s.region !== region && s.enabled));

if (order.length === 0) throw new Error("没有启用任何天气源");

let lastErr;

for (const s of order) {

try {

const data = await s.fetch(lat, lon);

if (data && data.cur) return data;

} catch (e) { lastErr = e; console.warn("[weather] 源 " + s.name + " 失败：", e); }

}

throw lastErr || new Error("所有源都失败");

}

```

**所以别人想加自己的 API 很简单**：写一个新函数把返回整理成 `{cur, daily, aqi, city}`，然后往 `SOURCES` 里 push 一个对象，并在 `weatherConfig.ts` 加个 `enableXxx` 开关。主流程（`pickSource`）完全不用改。

下面拿 **wttr.in** 举个完整例子（这个已经接进本项目并跑通了，不是假设）。它免费、免 Key、带 CORS 头，按 `:lat,:lon?format=j1` 出 JSON。坑在于它用 weather.com 那套天气代码（113=晴），跟现成的和风码(100+)/WMO码(0-99) 都不是一套，得先转成 WMO 码才能让图标表出图；另外日出日落是 `06:35 AM` 这种 12 小时制，得转成 24 小时。


```typescript

// weatherConfig.ts 里加一个开关

enableWttr: boolean; // wttr.in 数据源（免费免 Key，全球可用）

```


```javascript

// Weather.astro 里写归一化函数（插在 fetchOpenMeteoSource 之后、SOURCES 之前）

// wttr.in 的天气代码是 weather.com 那套（113=晴），转成 WMO 让 CODE 表能出图标

const WTTR_WMO = {

113:0,116:2,119:3,122:3,143:45,176:61,179:71,182:80,185:56,200:95,

227:73,230:73,248:45,260:48,263:53,266:53,281:56,284:57,293:61,296:61,

299:63,302:63,305:65,308:65,311:66,314:67,317:67,320:71,323:71,326:71,

329:73,332:73,335:75,338:75,350:77,353:80,356:81,359:82,362:80,365:81,

368:85,371:86,374:80,377:81,386:95,389:95,392:95,395:95,

};

// 日出日落是 "06:35 AM" 这种 12 小时制，转成 24 小时给 render

function ampmToHHmm(s) {

const m = /^(\d{1,2}):(\d{2})\s*(AM|PM)$/i.exec(s || "");

if (!m) return null;

let h = parseInt(m[1], 10); const min = m[2];

if (m[3].toUpperCase() === "PM" && h !== 12) h += 12;

if (m[3].toUpperCase() === "AM" && h === 12) h = 0;

return String(h).padStart(2, "0") + ":" + min;

}

async function fetchWttr(lat, lon) {

const r = await fetch("https://wttr.in/:" + lat + "," + lon + "?format=j1");

if (!r.ok) throw new Error("wttr.in " + r.status);

const d = await r.json();

const c = d.current_condition && d.current_condition[0];

if (!c) throw new Error("wttr.in 无当前天气");

const w0 = d.weather && d.weather[0];

const astro = w0 && w0.astronomy && w0.astronomy[0];

// 逐小时里的降雨概率取个最大值，填到 daily（没有就空着，render 显示 --）

let pop = 0;

if (w0 && Array.isArray(w0.hourly)) {

for (const h of w0.hourly) { const p = parseInt(h.chanceofrain, 10); if (!isNaN(p) && p > pop) pop = p; }

}

const cur = {

weather_code: WTTR_WMO[parseInt(c.weatherCode, 10)] != null ? WTTR_WMO[parseInt(c.weatherCode, 10)] : 3,

temperature_2m: Number(c.temp_C),

apparent_temperature: Number(c.FeelsLikeC),

relative_humidity_2m: Number(c.humidity),

wind_direction_10m: Number(c.winddirDegree),

wind_speed_10m: Number(c.windspeedKmph), // 已经是 km/h，beaufort 直接用

visibility: Number(c.visibility) * 1000, // km → m，对齐 render

surface_pressure: Number(c.pressure),

cloud_cover: Number(c.cloudcover),

uv_index: Number(c.uvIndex),

precipitation: Number(c.precipMM) || 0,

};

const daily = {

temperature_2m_max: w0 ? [Number(w0.maxtempC)] : [],

temperature_2m_min: w0 ? [Number(w0.mintempC)] : [],

sunrise: astro && ampmToHHmm(astro.sunrise) ? [ampmToHHmm(astro.sunrise)] : [],

sunset: astro && ampmToHHmm(astro.sunset) ? [ampmToHHmm(astro.sunset)] : [],

precipitation_probability_max: pop > 0 ? [pop] : [],

};

const area = d.nearest_area && d.nearest_area[0];

const city = (area && area.areaName && area.areaName[0] && area.areaName[0].value) || C.defaultCity;

return { cur, daily, aqi: null, city }; // wttr 免费接口不带空气质量，aqi 给 null，render 会显示 --

}

```

然后在 `SOURCES` 里加一行，`pickSource` 主流程一点不用动：

```javascript

{ name: "wttr", region: "global", enabled: C.enableWttr, fetch: (lat, lon) => fetchWttr(lat, lon) },

```

实测：wttr 返回 `113`（晴）被转成 WMO `0` → 图标出 ☀️；`06:35 AM`/`08:31 PM` 正确转成 `06:35`/`20:31`；AQI 因免费接口无数据而显示 `--`，

## 五、三个数据源的 fetch 与归一化

核心思路：`fetchUapis` / `fetchQWeather` / `fetchWeather` 各自把五花八门的返回格式，整理成同一个结构：

```typescript

{

cur: { temperature_2m, apparent_temperature, humidity, wind..., weather_code, ... },

daily: { temperature_2m_max:[], temperature_2m_min:[], sunrise:[], sunset:[], precipitation_probability_max:[] },

aqi: { current: { aqi, label, cls, pm2_5, pm10, o3, no2, so2, co } },

city: "城市名",

}

```

渲染层只认这个结构，不关心数据从哪来。

### 1. uapis.cn（国内主力，免 Key）

单接口把实时天气、空气质量、污染物、最高低温、日出日落、逐小时降水概率全给了，而且会自动按客户端 IP 定位（不传城市参数时）。它比较特别的是会**反射请求里的 `Origin` 头**返回 `Access-Control-Allow-Origin`，所以浏览器直连不跨域，不用自己搭代理。

```javascript

async function fetchUapis(lat, lon) {

// 不传 city/adcode，让它按客户端 IP 自动定位，最省事也最稳

const url = "https://uapis.cn/api/v1/misc/weather?lang=zh&extended=true&forecast=true&hourly=true";

const r = await fetch(url, { headers: { Accept: "application/json" } });

if (!r.ok) throw new Error("uapis " + r.status);

const j = await r.json();

if (!j || (j.city == null && j.weather == null)) throw new Error("uapis empty");



// 风向它给的是"东北风"这种文字，先转成角度；逐小时里没有风就退化用风力等级

const hourly = Array.isArray(j.hourly_forecast) ? j.hourly_forecast : [];

const dirDeg = dirTextToDeg(j.wind_direction);

const windKmh = hourly[0] && hourly[0].wind_speed != null

? Number(hourly[0].wind_speed)

: windPowerToKmh(j.wind_power);

// 整理成统一结构。uapis 的 weather_icon 就是和风那套天气代码，直接拿去查映射表

const cur = {

temperature_2m: Number(j.temperature),

apparent_temperature: Number(j.feels_like),

relative_humidity_2m: Number(j.humidity),

cloud_cover: Number(j.cloud),

surface_pressure: Number(j.pressure),

wind_speed_10m: windKmh,

wind_direction_10m: dirDeg,

visibility: Number(j.visibility) * 1000, // 它给的是 km，统一成米

uv_index: Number(j.uv),

precipitation: Number(j.precipitation) || 0,

weather_code: Number(j.weather_icon),

};

// 逐小时里挑今天的，取最大降水概率

let popMax = null;

for (const h of hourly) {

const p = Number(h.pop);

if (!isNaN(p)) popMax = popMax == null ? p : Math.max(popMax, p);

}



const f0 = j.forecast && j.forecast[0] ? j.forecast[0] : {};

const daily = {

temperature_2m_max: [Number(f0.temp_max)],

temperature_2m_min: [Number(f0.temp_min)],

sunrise: [f0.sunrise || ""],

sunset: [f0.sunset || ""],

precipitation_probability_max: [popMax != null ? Math.round(popMax) : null],

};



// 空气质量 + 污染物。co 有的接口不返回，拿不到就留 null

const ap = j.air_pollutants || {};

const aqi = {

current: {

label: j.aqi_category || "--", // "优" / "良" 这种中文

cls: mapCategory(j.aqi_category), // 映射成 aqi-good 之类的颜色类

aqi: j.aqi != null ? Number(j.aqi) : null,

pm2_5: ap.pm25 != null ? Number(ap.pm25) : null,

pm10: ap.pm10 != null ? Number(ap.pm10) : null,

o3: ap.o3 != null ? Number(ap.o3) : null,

no2: ap.no2 != null ? Number(ap.no2) : null,

so2: ap.so2 != null ? Number(ap.so2) : null,

co: ap.co != null ? Number(ap.co) : null,

},

};

const city = j.city || C.defaultCity; // IP 定位返回的就是城市名，简单够用

return { cur, daily, aqi, city };

}

```

两个小工具：`dirTextToDeg` 把"东北风"翻译成角度（先匹配"东北"再匹配"北"，避免被单字抢先），`windPowerToKmh` 把"3级"翻译成近似 km/h 好算风力等级：

```javascript

function dirTextToDeg(t) {

const m = { 东北: 45, 东南: 135, 西南: 225, 西北: 315, 北: 0, 东: 90, 南: 180, 西: 270 };

if (!t) return 0;

const order = ["东北", "东南", "西南", "西北", "北", "东", "南", "西"];

for (const k of order) if (t.indexOf(k) >= 0) return m[k];

return 0;

}

function windPowerToKmh(p) {

const m = p && p.match(/(\d+)/);

const lvl = m ? Math.min(Number(m[1]), 12) : 0;

const tbl = [0, 3, 8, 15, 24, 33, 44, 56, 68, 82, 96, 110, 120]; // 每级取个中间值

return tbl[lvl] != null ? tbl[lvl] : 0;

}

```

### 2. 和风天气（国内兜底，有 Key 才用）

uapis 挂了就切它。和风是实时优先、7 天兜底的混合策略：实时接口优先，缺的字段（比如最高低温）用 7 天预报补。

```javascript

async function fetchQWeather(lat, lon, key) {

const loc = lon + "," + lat;

const base = (C.qweatherHost || "https://api.qweather.com/v7").replace(/\/$/, "");

const geoBase = (C.qweatherGeoHost || "https://geoapi.qweather.com/v2").replace(/\/$/, "");

const aqHost = base.replace(/\/v7$/, ""); // 实时/空气质量的 Host 要去掉 /v7

const now = new Date();

const pad = (n) => String(n).padStart(2, "0");

fetch(aqHost + "/airquality/v1/current/" + lat + "/" + lon + "?key=" + key),

fetch(geoBase + "/city/lookup?location=" + encodeURIComponent(loc) + "&key=" + key),

fetch(base + "/v7/astronomy/sun?location=" + encodeURIComponent(loc) + "&date=" + ymd + "&key=" + key),

]);

const hr = hrR.ok ? await hrR.json() : null;

const d7 = d7R.ok ? await d7R.json() : null;

const aq = aqR.ok ? await aqR.json() : null;

const geo = geoR.ok ? await aqR.json() : null;

const sun = sunR.ok ? await sunR.json() : null;

temperature_2m: Number(curJ.temperature?.value),

apparent_temperature: Number(curJ.feelsLike?.value),

relative_humidity_2m: Math.round(Number(curJ.humidity?.value)),

cloud_cover: Math.round(Number(curJ.cloudCover) * 100), // 0~1 的比例，乘 100 变百分比

surface_pressure: Number(curJ.pressure?.value),

wind_speed_10m: Math.round(Number(curJ.windSpeed?.value) * 3.6), // m/s 转 km/h

wind_direction_10m: Number(curJ.windDir?.value),

visibility: Number(curJ.visibility?.value),

uv_index: Number(curJ.uvIndex?.value),

weather_code: Number(cond.code), // 和风代码（字符串）转数字，渲染时查映射表

};

let tMin = day0.tempMin != null ? Number(day0.tempMin) : null;

if (hr && hr.hours) {

const d = new Date(h.forecastTime);

return k === now.getFullYear() + "-" + pad(now.getMonth() + 1) + "-" + pad(now.getDate());

});

for (const h of src) {

const t = Number(h.temperature?.value);

if (!isNaN(t)) { mx = mx == null ? t : Math.max(mx, t); mn = mn == null ? t : Math.min(mn, t); }

const p = Number(h.precipitation?.probability); // 注意字段叫 probability，不是 pop

if (!isNaN(p)) popMax = popMax == null ? p : Math.max(popMax, p);

}

if (mx != null) tMax = mx;

if (mn != null) tMin = mn;

}

temperature_2m_max: [tMax],

temperature_2m_min: [tMin],

sunrise: [sun?.sunrise || day0.sunrise || ""],

sunset: [sun?.sunset || day0.sunset || ""],

precipitation_probability_max: [popMax != null ? Math.round(popMax) : null],

};

// 空气质量：和风给的是污染物数组，按 code 找浓度

let aqi = { current: null };

if (aq && aq.now) {

const ps = aq.pollutants || [];

const conc = (code) => {

const p = ps.find((x) => x.code === code);

return p && p.concentration && p.concentration.value != null ? Number(p.concentration.value) : null;

};

aqi = {

cls: mapCategory(idx ? idx.category : ""),

aqi: idx ? Number(idx.aqi) : null,

pm2_5: conc("pm2p5"), pm10: conc("pm10"), o3: conc("o3"),

no2: conc("no2"), so2: conc("so2"), co: conc("co"),

},

};

}

// 城市反查：adm2 是市，name 是区/县，拼成"钦州市钦南区"这种

const g = geo.location[0];

}

return { cur, daily, aqi, city };

}
```

## 六、踩坑实录（这篇最值钱的部分）

### 坑 1：Astro scoped CSS 对 JS 动态创建的元素完全失效

污染物那几个小格子（`PM₂.₅` 这种）是 `document.createElement` 现造的。Astro 的 `<style>` 会给选择器自动加一个 scoped 属性（类似 `.pc-label[data-astro-cid-xxx]`），**而 JS 造出来的元素没有这个属性**，于是 `.pollutant-chip` / `.pc-label` / `.pc-val` 全都不命中——肉眼看就是所有文字挤成一行、`PM2.56 pm1026 ...`。

解决办法：凡是给 JS 动态 DOM 用的样式，一律用 `:global()` 包起来，绕过 scoped 隔离。文章第四节的 CSS 就是这么写的。

```css

/* 错的：scoped 属性匹配不上动态元素 */

.pollutant-chip .pc-label { ... }

/* 对的：用 :global 让它全局生效 */

:global(.pollutant-chip .pc-label) { ... }

```

同理，暗色模式 `.dark` 也是挂在 `<html>` 上的全局类，所以 `:global(.dark) .detail-card` 也得加 `:global`。

### 坑 2：localStorage 缓存把 AQI 解包搞没了

为了不每次都弹定位授权、不重复请求，我把结果缓存 10 分钟。一开始写缓存时手滑把 `aqi` 解包了：

```javascript

// 错的：只存了内层

localStorage.setItem(KEY, JSON.stringify({ aqi: data.aqi?.current ?? null, ... }));

// 渲染时却读 aqi.current → 缓存回读后 .current 是 undefined → AQI 和污染物全显示 --

```

表现很迷惑：**首次加载正常，10 分钟内刷新（命中缓存）就全变 `--`**。

修法：缓存存完整的 `data.aqi` 原对象，渲染层再兼容读取：

```javascript

// 对的：连外层一起存

localStorage.setItem(KEY, JSON.stringify({ t: Date.now(), cur: data.cur, daily: data.daily, aqi: data.aqi, city: data.city }));

```

渲染时兜底一下结构差异：

```javascript

const aqiRaw = aqi;

// 兼容两种形态：{current:{...}} 或 直接 {aqi, pm2_5...}

const aqiCur = (aqiRaw && aqiRaw.current)

? aqiRaw.current

: ((aqiRaw && typeof aqiRaw.aqi === "number") ? aqiRaw : null);

```

### 坑 3：Swup 页面切换，脚本不重入

站点用了 Swup 做页面过渡，它替换 DOM 但不重新跑 `<script>`。如果只监听一次 `astro:page-load`，从别的页切回来时组件就永远不会更新，卡在"定位中…"。

解决：脚本最末尾同时做两件事——首屏直接跑一次（侧边栏 DOM 已在），再挂 `astro:page-load` 监听后续 SPA 导航；用 `ran` 标记防重复执行。

```javascript

let ran = false;

function runWeather() {

if (ran) return; // 已经渲染过就别重复跑了

ran = true;

initWeather();

}

runWeather(); // 首屏直接跑

document.addEventListener("astro:page-load", runWeather); // 后续导航重入

```

### 坑 4：城市名显示不全

uapis 返回的 `city` 只是城市名（如"钦州"），没有区。一开始我为了让它显示"钦州市钦南区"，在国内分支也加了一次 reverseGeocode 反查。后来觉得没必要——侧边栏那么小，显示市就够了，干脆去掉，直接用 uapis 给的城市名。

如果哪天你想显示完整区名，把下面这段加回国内分支（`fetchUapis` / `fetchQWeather` 之后）就行，逻辑跟国外分支一致：

```javascript

const g = await reverseGeocode(lat, lon, getGeocodeLang());

if (g) {

const c = g.city || "";

const l = g.locality || "";

const fullCity = (c && l && l.startsWith(c)) ? l : (c + l) || g.principalSubdivision;

if (fullCity) data.city = fullCity;

}

```

```astro
// 风向角度 → 中文方位

function windDir(deg) {

const dirs = ["北", "东北", "东", "东南", "南", "西南", "西", "西北"];

const i = Math.round(((deg + 180 / 8) % 360) / 45) % 8;

return dirs[i];

}

// 风速 km/h → 蒲福风力等级

function beaufort(kmh) {

if (kmh < 1) return 0;

if (kmh <= 5) return 1; if (kmh <= 11) return 2; if (kmh <= 19) return 3;

if (kmh <= 28) return 4; if (kmh <= 38) return 5; if (kmh <= 49) return 6;

if (kmh <= 61) return 7; if (kmh <= 74) return 8; if (kmh <= 88) return 9;

if (kmh <= 102) return 10; if (kmh <= 117) return 11;

return 12;

}

// "东北风"这种文字 → 角度，先匹配两字方向再匹配单字

function dirTextToDeg(t) {

const m = { 东北: 45, 东南: 135, 西南: 225, 西北: 315, 北: 0, 东: 90, 南: 180, 西: 270 };

if (!t) return 0;

const order = ["东北", "东南", "西南", "西北", "北", "东", "南", "西"];

for (const k of order) if (t.indexOf(k) >= 0) return m[k];

return 0;

}

// "3级"这种文字 → 近似 km/h，取蒲福级中点

function windPowerToKmh(p) {

const m = p && p.match(/(\d+)/);

const lvl = m ? Math.min(Number(m[1]), 12) : 0;

const tbl = [0, 3, 8, 15, 24, 33, 44, 56, 68, 82, 96, 110, 120];

return tbl[lvl] != null ? tbl[lvl] : 0;

}

// 和风的空气质量是"优/良"中文，映射成颜色类

function mapCategory(cat) {

if (cat === "优") return "aqi-good";

if (cat === "良") return "aqi-moderate";

if (cat === "轻度污染") return "aqi-unhealthy-sg";

if (cat === "中度污染") return "aqi-unhealthy";

if (cat === "重度污染") return "aqi-very-unhealthy";

if (cat === "严重污染") return "aqi-hazardous";

return "";

}

// 站点语言 → 地理编码语言码，城市名跟着站点语言走

if (lang.startsWith("en")) return "en";

if (lang.startsWith("ja")) return "ja";

if (lang.startsWith("ko")) return "ko";

if (lang.startsWith("ru")) return "ru";

return "zh-CN";

}

// 和风的城市反查结果拼成"市+区"

}

return name || adm2 || adm1 || "";

}

// 数据源注册表：想加自己的 API，照着 push 一个对象、写个 fetch 函数就行，不用动主流程

// region 标 "cn" 表示国内优先、"global" 表示国外；enabled 由配置开关控制（和风还需有 Key）

const SOURCES = [

{ name: "uapis", region: "cn", enabled: C.enableUapis, fetch: (lat, lon) => fetchUapis(lat, lon) },

{ name: "qweather", region: "cn", enabled: C.enableQWeather && !!C.qweatherKey, fetch: (lat, lon) => fetchQWeather(lat, lon, C.qweatherKey) },

];


// 先试本区 enabled 的源，全挂再跨区兜底

async function pickSource(lat, lon, region) {

const primary = SOURCES.filter((s) => s.region === region && s.enabled);

const fallback = SOURCES.filter((s) => s.region !== region && s.enabled);

const order = primary.concat(fallback);

if (order.length === 0) throw new Error("没有启用任何天气源");

let lastErr;

for (const s of order) {

try {

const data = await s.fetch(lat, lon);

if (data && data.cur) return data;

} catch (e) {

lastErr = e;

console.warn("[weather] 数据源 " + s.name + " 失败，尝试下一个：", e);

}

}

throw lastErr || new Error("所有数据源都失败了");

}

// 带硬性超时的定位：系统 API 的 timeout 不靠谱，自己加个 5 秒兜底

async function getPosition() {

if (!C.autoLocate || !navigator.geolocation) return null;

return new Promise((res) => {

let done = false;

const finish = (v) => { if (!done) { done = true; res(v); } };

const timer = setTimeout(() => finish(null), 5000);

try {

navigator.geolocation.getCurrentPosition(

(pos) => { clearTimeout(timer); finish(pos); },

() => { clearTimeout(timer); finish(null); },

{ timeout: 5000, maximumAge: 10 * 60 * 1000 },

);

} catch { clearTimeout(timer); finish(null); }

});

}

if (toggle && !toggle.dataset.bound) {

toggle.dataset.bound = "1";

toggle.addEventListener("click", () => {

const open = el.classList.toggle("is-open");

toggle.setAttribute("aria-expanded", open ? "true" : "false");

toggle.setAttribute("aria-label", open ? "收起天气详情" : "展开天气详情");

}

// 10 分钟内读缓存，避免反复弹授权 / 重复请求

const cached = localStorage.getItem(CACHE_KEY);

if (cached) {

try {

const o = JSON.parse(cached);

if (Date.now() - o.t < 10 * 60 * 1000) {

render(el, o.cur || o.current, o.daily, o.aqi, o.city);

return;

}

} catch {}

}

let lat, lon;

const p = await getPosition();

if (p) { lat = p.coords.latitude; lon = p.coords.longitude; }

if (lat == null) { lat = C.defaultLat; lon = C.defaultLon; }

try {

// 按坐标判断国内/国外，从注册表里挑一个能用的源（本区优先，失败再试其它区兜底）

const region = isInChina(lat, lon) ? "cn" : "global";

const data = await pickSource(lat, lon, region);

render(el, data.cur, data.daily, data.aqi, data.city);

// 缓存存完整对象（含 aqi 外层），别解包，否则回读时 .current 没了

localStorage.setItem(CACHE_KEY, JSON.stringify({

t: Date.now(), cur: data.cur, daily: data.daily, aqi: data.aqi, city: data.city,

}));

} catch {

setText(el, ".weather-city", "获取失败");

setText(el, ".weather-desc", "请检查网络");

}

}

// 首屏直接跑一次；Swup 导航会再派发 astro:page-load，用 ran 防重复

let ran = false;

function runWeather() {

if (ran) return;

ran = true;

initWeather();

}

runWeather();

document.addEventListener("astro:page-load", runWeather);

</script>
```
